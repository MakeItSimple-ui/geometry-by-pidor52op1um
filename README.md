# Чертежи — свой сайт для GeoGebra

Статический сайт-галерея: превьюшки, разделы, поиск, а по клику — интерактивный
чертёж во весь экран. Друзьям можно кидать прямую ссылку на конкретный чертёж.

## Что где

```
index.html          галерея
view.html           просмотр одного чертежа
assets/             стили и скрипты
sources.json        аккаунт GeoGebra и его папки — откуда тянуть чертежи автоматом
links.json          чертежи, добавленные руками (по material id)
ggb/                твои .ggb файлы (подпапки = разделы)
thumbs/             превьюшки, генерируются сами из .ggb
manifest.json       собирается автоматически, руками не трогать
scripts/            сборка манифеста
```

## Как выложить на GitHub Pages

1. Создать репозиторий на GitHub, залить туда эту папку (ветка `main`).
2. **Settings → Pages → Build and deployment → Source: GitHub Actions.**
3. Пуш запускает сборку. Через минуту сайт на `https://<ник>.github.io/<репо>/`.

### Свой домен

1. **Settings → Pages → Custom domain** → вписать домен → Save.
2. У регистратора домена добавить записи:
   * для `chertezhi.example.com` — `CNAME` → `<ник>.github.io`
   * для голого `example.com` — четыре `A`-записи на
     `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
3. Подождать проверку и включить **Enforce HTTPS**.

## Как добавить чертёж

**Само собой — если чертёж публичный.**
Сборка раз в 3 часа ходит в твой аккаунт GeoGebra и забирает оттуда всё новое:
название, превью, раздел (по папке) — всё подтянется само, и переименования тоже.

Одно условие: GeoGebra отдаёт наружу только чертежи со статусом **Public**.
В чертеже: Share → выставить *Public*. Вариант «Shared with link» в списке
не виден никому, кроме тебя, — такие в сборку не попадут, их надо добавлять руками
(вариант Б) либо переключить на Public.

Папки заданы в `sources.json` по их id (хвост ссылки `geogebra.org/f/xxxx`).
Заведёшь новую папку в GeoGebra — допиши туда строку, и появится новый раздел.
Чертежи вне папок попадают в «Без раздела».

Если GeoGebra недоступна, сборка не падает — сайт остаётся с тем, что уже было.

**Вариант А — своим файлом (чертёж живёт у тебя).**
В GeoGebra: открыть чертёж → ⋮ → Download → *GeoGebra File (.ggb)*.
Закинуть файл в `ggb/` (или в подпапку — она станет разделом).
Имя файла = название на сайте. Превью достанется из файла само.

На GitHub это делается прямо в браузере: папка `ggb` → **Add file → Upload files** →
перетащить → Commit. Через минуту чертёж на сайте.

**Вариант Б — руками, ссылкой.**
Для «shared with link» и вообще всего, что не подтянулось само.
Дописать объект в `links.json`:

```json
{ "id": "pzx7xumx", "title": "колм 25-26", "folder": "планик" }
```

`id` — хвост ссылки `geogebra.org/m/pzx7xumx` (можно вставить и ссылку целиком).
`folder` — любой, новый раздел появится сам. `thumb` — ссылка на картинку-превью,
необязательно. `perspective: "T"` — если чертёж стереометрический и открываться
должен сразу в 3D (обычно определяется автоматически).

> Ссылки работают, пока чертёж в GeoGebra публичный или «Shared with link».
> Хочешь независимости — переливай в `ggb/` файлами.

## Локально

```bash
npx serve .        # открыть http://localhost:3000
```

Просто открыть `index.html` двойным кликом не получится — браузер не даст
прочитать `manifest.json` с `file://`.

## Пересобрать манифест руками

```bash
node scripts/build-manifest.mjs
```
