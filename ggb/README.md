# Сюда кидаешь .ggb файлы

Правила простые:

* **имя файла = название на сайте.** `тургор 2025 11.6.ggb` → на сайте будет «тургор 2025 11.6»
* **подпапка = раздел на сайте.** Положил в `ggb/стерео/` → попадёт в раздел «стерео».
  Положил прямо сюда, без подпапки → раздел «Без раздела».
  Новую папку создаёшь просто так — новый раздел появится сам.
* превьюшку вытаскивать не надо, она уже лежит внутри `.ggb` — сборка достанет сама.

Как скачать `.ggb` из GeoGebra: открыть чертёж → ⋮ → **Download** → *GeoGebra File (.ggb)*.
